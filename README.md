# Coming Soon Page

Terminal-style coming soon page with countdown timer and contact options.

## Features

- Countdown timer with progress bar (ETA: 2026-03-15)
- Email/Message toggle (WhatsApp & SMS)
- Auto light/dark mode
- Responsive design

## Usage

Open `index.html` in your browser.
